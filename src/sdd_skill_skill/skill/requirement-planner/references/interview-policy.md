# Interview Policy

Ask only questions that can change at least one of:

- runtime behavior;
- implementation boundary;
- acceptance criteria;
- data, API, UI, infrastructure, migration, or compatibility scope;
- conflict resolution between source facts and project facts.

Do not ask questions answered by repository evidence. Do not ask template-filling
questions.

Each question must include:

- question ID `Q-###`;
- severity: Blocking, Important, or Non-blocking;
- why the answer matters;
- source evidence;
- repository evidence;
- two or three mutually exclusive options;
- impact of each option;
- recommendation when evidence supports one.

Ask at most three questions per batch. Blocking questions must be resolved before
the spec can be Ready for Implementation.
